MALOVISKY IT TOOLS

VERSAO 1.4.0 · NOVO: GERENCIADOR DE HOSTS

Ferramentas de suporte e manutencao Windows via PowerShell, com interface Matrix e atualizacoes pelo GitHub.

Menu de ferramentas

01. AnyDesk

Instalacao, reinstalacao limpa, diagnostico e abertura elevada apos instalacao.

02. Firewall

Simulacao, aplicacao e remocao controlada de regras por fabricante.

03. Otimizacao Windows

Rotinas de manutencao e reparo do sistema operacional.

04. Autodesk Deep Clean

Simulacao ou limpeza de residuos Autodesk, Autodesk Shared e licencas Autodesk no FLEXnet, com logs e confirmacoes.

05. Gerenciador de HOSTS NOVO

Consulta e remocao individual de linhas, redefinicao para o padrao Windows com hosts.bkp e restauracao do backup.

Como executar

Confira o codigo antes de executar e abra o Windows PowerShell em um equipamento autorizado:

irm https://scripts.malovisky.com.br | iex

Atencao: ferramentas potencialmente destrutivas. Faça backup. O Autodesk Deep Clean deve ser utilizado apos desinstalacao oficial; o modo de execucao requer confirmacao e privilegios administrativos. Limpar FlexNet compartilhado pode afetar outros fabricantes. Redefinir HOSTS remove entradas personalizadas que podem ser necessarias para sistemas internos.

Ver codigo-fonte, novidades e documentacao no GitHub
